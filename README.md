
## Skill Overview

- [**pr-workflow**](skills/pr-workflow/SKILL.md) — git workflow for pushing and opening PRs: confirm intent, branch off main with Conventional-Commit names, conventional PR titles, and the repo's PR template verbatim
- [**code-organization**](skills/code-organization/SKILL.md) — TypeScript file-organization convention: dedicated folders for types, schemas, utils, and constants, grouped by domain, no barrel files
- [**talking-head-edit**](skills/talking-head-edit/SKILL.md) — edit phone-shot founder videos for X, TikTok and Reels: fumble cuts with soft dissolves, Apple HDR tone mapping plus a film look, synced captions, logo cards, cloud renders
- [**text-behind-subject**](skills/text-behind-subject/SKILL.md) — the reel edit where big caption words sit behind your head: phone upload link, iPhone HDR to SDR, LUT grade picked with media-use, person matting, legibility-aware text placement
